create

Groups your members build themselves

group creation

Group creation open to every member — or just your admins

Enable social group creation by all members, or keep it admin-only — administrators can always create groups regardless. On the frontend, a five-step Create-a-Group wizard walks members through Details, Privacy, Photo, Invites, and Courses.

group message

Message every group member at once

Allow for sending group messages to group members, straight from the group. The composer even switches between Group message and Private message, with every group member on the To: line.

identity

Every group, dressed for your community

cover image sizes

Cover sizes tuned to your directory’s density

Set cover image Width (Full Width) and Height (Small) for the whole network from one row of dropdowns. Change carefully — resizing repositions covers members have already uploaded, and the admin warns you first.

Default group avatar

A default avatar for groups that skip the upload

Pick what new groups wear before anyone uploads: the BuddyBoss mark, the group’s name, or a custom image you provide (JPG or PNG, 300×300 px). No gray placeholders anywhere in your directory.

Default group cover

Default covers so no group launches bare

Choose the fallback for groups without a cover: BuddyBoss, none, or a custom image (JPG or PNG, 1950×450 px). Set it once in the admin, and every new group starts dressed.

header style

A group header style that matches your brand

Choose Left or Centered for every group header — avatars and covers appear only if you’ve enabled them. One radio in the admin restyles every group page (the App style keeps its own layout).

header elements

Header elements you switch on and off

Five toggles decide what group headers show: Group Type, Last Activity, Group Description, Group Organizers, and Group Privacy. Type, activity, and privacy ship on by default — the rest is your call.

discover

A directory that sells your groups

directory layout

A groups directory in grid, list, or both

Display group directories in Grid View, List View, or let members toggle between both. The frontend keeps the switcher in the directory header, right next to the Type and Activity filters.

directory elements

Eight directory elements, entirely your call

Toggle what each directory card shows: Cover Images, Avatars, Group Privacy, Group Type, Last Activity, Members, Group Descriptions, and Join Buttons. Covers render only in grid view; descriptions only in list view.

manage

Who creates, who joins, who runs it

create groups

Decide who can create social groups

Select which members can create groups based on WordPress Role or Profile Type, with a per-role toggle list. Administrators are always exempt — these controls never apply to them.

join groups

Joining rules for public and private groups

Select which members can join public groups or request to join private groups, by WordPress Role or Profile Type. On the frontend it’s one button: Join Group on public groups, Request Access on private ones.

group types

Group types that organize the whole network

When enabled, group types let you better organize groups — custom labels, per-type role names, directory visibility, and label colors, plus a shortcode to list any type on its own page. Five types or fifty, each one badge-coded.
